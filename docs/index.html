Mozg

One GraphQL endpoint that queries 47 public life-science databases live and joins their answers.

  • Queries run against each source at request time. The README calls this “slow by design”: freshness and flexibility over speed.
  • A single request can join UniProt, PDBe, AlphaFold and Reactome, then follow an OBO key into Open Targets (see the clip).
  • Also connects PostgreSQL, SQLite, MySQL, Neo4j, ArangoDB and Elasticsearch, and ships a query builder that runs in the browser.
  • Every source’s example and relation is checked against the live APIs weekly. Helm charts deploy self-hosted databases that scale to zero (beta).

Status in its README: life-science sources, PostgreSQL and SQLite are stable; the other drivers are beta.

  • Node.js
  • GraphQL
  • Helm

mycelium

A knowledge-graph workbench for biological data: add files, annotate them with domain entities, explore the graph.

  • Started as a fork of Lifelike (SBRG). Modernised to Angular 22, Flask 3, d3 7 and Bootstrap 5, with the PDF viewer patched for CVE-2024-4367.
  • Built-in viewers for PDF, Office files, protein structures (Mol*) and code. Local folders open without uploading and are indexed in the background.
  • Visualisations: maps, enrichment tables, Sankey diagrams and a pathway browser.
  • Zero-config dev container and Codespaces, Playwright end-to-end tests, CI for tests, Docker publishing, CodeQL and Dependabot auto-merge. Panels use route-with-dynamic-outlets.

This project uses code provided by Lifelike.bio.

nf-mapper

Turns a Nextflow pipeline into a Mermaid git graph, straight from its .nf source.

  • Parses DSL2 with Nextflow’s official AST library. Each process becomes a commit; the main chain stays on main, QC and parallel steps branch off. A second renderer turns if/else blocks into labelled branches.
  • A CLI (fat JAR), a Docker image and a GitHub Action. --update rewrites a diagram block inside an existing Markdown file, so docs stay in sync in CI.
  • Output pastes into GitHub Markdown, Notion or Confluence. Themes: nf-core colours or plain.
  • Tested against nf-core/fetchngs, nf-core/rnaseq modules and bigbio/quantms.
  • Java 17
  • Maven
  • Mermaid
  • Nextflow
  • Docker

nf-migrate

Applies nf-core template updates as a chain of small, idempotent migrations instead of one large git merge.

  • One migration per nf-core/tools release, made of operations such as Replace, YamlSet and BumpVersion. No LLM involved.
  • A GitHub Action resolves the template sync PRs opened by nf-core-bot and comments the manual steps that are left (for example nf-core modules update) as a checklist.
  • Matching tolerates what pipelines routinely change around template text: spacing, list indentation, resolved TODO notes.
  • Tuned against every merged template update of the nf-core pipelines list (figures from its validation notes).
  • Python 3.12
  • GitHub Action
  • nf-core

    Neuroform

    A brain-shaped cloud of points wired by synapses. Touch a node and a wave of activation spreads through the tissue.

    • The animation at the top of this page is this component running live. Signals travel along connections at a finite speed and charge what they reach; whatever crosses its threshold fires in turn.
    • Click a node to fire it, drag to orbit, scroll to zoom, space fires a random node, r quiets the network.
    • Ships as a <neuro-form> web component. Every setting is an attribute, and it installs straight from GitHub.
    • GitHub Pages publishes the site and a live preview of every open pull request.
    • TypeScript
    • three.js
    • Vite

    serverless-office-converter

    Converts Word, Excel, PowerPoint and OpenDocument files in the browser. LibreOffice runs as WebAssembly, so nothing is uploaded.

    • Offers 460 input and output combinations, from DOCX, XLSX, PPTX, ODT, RTF and Markdown to PDF, PDF/A, Office, OpenDocument and image formats. The README reports that every one produces a valid file.
    • Works offline once loaded; the engine is a one-time download of about 28 MB that the browser caches. The README shows how to check in DevTools that no request carries a document.
    • Handles batches and whole folders. In Chrome and Edge it can save next to the originals and watch a folder for new files.
    • Plain static files on GitHub Pages, installable as a PWA. There is no server component.
    • WebAssembly
    • Emscripten

    azure-data-lake-fs

    A Python client for Azure Data Lake Storage Gen2 that works around the 64-record ACL limit.

    • Named-user ACL entries are converted into lazily created permission groups, so access lists stay under 64 records.
    • ACL reads redact principal object IDs.
    • Uploads and downloads return SAS URL contexts, so file bytes do not pass through the library.
    • An optional Service Bus queue observer handles changes, and a Bicep template provisions storage, Service Bus and the Event Grid wiring.
    • Python
    • Azure
    • Bicep
    • pytest
